# 🌤️ Modern Weather Application

A clean, responsive, and real-time weather application built with **React**, **Axios**, and **Lucide React** icons. This app allows users to check current weather conditions, temperatures, wind speeds, and atmospheric details for any location with a smooth user experience.

---

## ✨ Features

- 🌡️ **Real-Time Weather Data**: Fetch accurate temperature, humidity, pressure, and weather conditions using OpenWeatherMap API.
- 💨 **Wind Speed & Direction**: Calculated and formatted wind speed in km/h along with directional indicators.
- 🎨 **Modern UI & Icons**: Sleek interface powered by **Lucide React** (`lucide-react`) icons.
- ⚡ **Fast & Responsive**: Fully responsive layout designed for mobile, tablet, and desktop views.
- 🔄 **Dynamic Loaders**: Custom loading spinners and smooth feedback during data fetching.

---

## 🛠️ Tech Stack & Libraries

- **Frontend**: [React](https://react.dev/) (Hooks: `useState`, `useEffect`)
- **HTTP Client**: [Axios](https://axios-http.com/) (API Integration)
- **Icons**: [Lucide React](https://lucide.dev/) (`lucide-react`)
- **Styling**: CSS3 / Tailwind CSS
